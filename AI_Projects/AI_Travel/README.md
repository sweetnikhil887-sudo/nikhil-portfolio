# AI Travel

## Project Vision

AI Travel ek simple virtual travel platform hoga jahan user ghar baithe duniya ki famous locations ko explore kar sake.

User ek AI Guide ko control karega aur uske saath virtual tour karega.

### Goals

- Simple UI
- Easy Navigation
- Voice Commands
- AI Guide
- Famous Places
- Learning + Travel Experience
